### Review findings rejected (verified false-positive / intentional) — UI mock-match
- **Batch dispatch "uses live GST%":** the batch only *creates* dispatches and snapshots `part.gstPct` at apply time — identical to single-line create. The snapshot-preserve logic exists only for *edits* (which the batch never does), and `validate`/`apply` run synchronously in one `runCommand` (no render→save window). Behaviour is correct.
- **Hardcoded logo/avatar gradients:** intentional fixed accents on an always-dark rail — they should NOT theme-adapt.
- **NavLink missing `aria-current`:** React Router's `NavLink` sets `aria-current="page"` automatically.
- **`numOf` negative coercion:** guarded upstream by `min={0}` number inputs and the command validator.
- **Color-only status pills / KPI accent aria-hidden / nested-table scope / `_seq` keys / action-cell propagation:** verified non-defects.

## Known risks being carried (not yet bugs)
- localStorage ~5 MB quota can silently drop writes on long sessions → P9 quota-guard toast (adapt `storageQuota.ts`).
- Client-side-only RBAC (localStorage edit = admin) — accepted constraint of a frontend-only app; documented, not a defect.
- `@react-pdf/renderer` + `xlsx` are heavy → must be lazy/code-split (P9 perf).
- **Deferred low-priority (review):** `kpi.ts` re-derives "open challan" instead of reusing `selectInwardBalance` (agrees today; single-source later); `Modal` body-scroll lock isn't a shared counter (only matters for stacked modals); `Tooltip` on a *disabled* button gives no keyboard hint (informational only); sidebar active state relies on a color tint + NavLink `aria-current`; `TableSkeleton` has no announced loading status. None block P1.
- **Deferred low-priority (P1 masters review):** PAN/IFSC are free-form (no format guard — deliberate for now); opening-stock `(unit,part,fy)` uniqueness not enforced (duplicates would double-count — add a refine in P3 import); rate masters log with `unitId` undefined so a unit-filtered audit omits rate changes (rates are multi-unit by nature). None block P2.
- **Deferred low-priority (P2 register review):** `useShallow` over the row selectors is effectively a no-op (each call builds fresh objects) → memoize derived row selectors in **P9 perf** (also the >500 kB JS chunk → code-split `@react-pdf/renderer`/`xlsx`); expand disclosure lacks `aria-controls`; Modal backdrop uses literal `bg-black/50` (accepted overlay); no hard `(unit,billNo)` uniqueness invariant across invoices (mitigated: linking is draft-only + issued-bill clash is rejected); inward↔part unit consistency not enforced on inward save (analogous to opening — add in P3 import). None block P3.
